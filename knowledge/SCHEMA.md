# Wiki Schema

Simple project, simple wiki. One main page covers the site; log and index keep things findable.

## Pages

| File | Purpose |
|------|---------|
| `site.md` | Site overview: stack, content, deployment, structure |
| `log.md` | Chronological decisions and changes |
| `index.md` | Page catalogue |
| `SCHEMA.md` | This file |

## Conventions

- Dates: YYYY-MM-DD
- Log entries: newest first
- Links: relative markdown links between wiki pages
