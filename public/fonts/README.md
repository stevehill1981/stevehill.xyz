# Self-hosted type

Source Sans 3 and Bitter are variable fonts served locally in the 400–700 weight range, with `font-display: swap` in `src/styles/site.css`.

Latin WOFF2 subsets were obtained from the official Google Fonts stylesheet service on 15 October 2026:

- `https://fonts.googleapis.com/css2?family=Source+Sans+3:wght@400..700&display=swap`
- `https://fonts.googleapis.com/css2?family=Bitter:wght@400..700&display=swap`

The files total 62,960 bytes. Their SIL Open Font Licenses are retained beside them, sourced from the respective `ofl/sourcesans3/OFL.txt` and `ofl/bitter/OFL.txt` files in the official `google/fonts` repository. No remote stylesheet or font host is required by the built site.
